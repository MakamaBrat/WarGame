Art of War 2 — Global Confederation: нативный веб-порт (без эмулятора и без Java).

Запуск: открыть index.html (работает и с file://), либо выложить папку на любой хостинг.
Файлы: index.html (страница, раскладка, настройки), touch.js (жесты), runtime.js (MIDP: Canvas 2D, RMS, PNG, MIDI),
       game.js (игра, транслированная из байткода WarStr.jar), data.js (ресурсы), startup.js (старт сразу в меню, тап по карте).
Пересборка game.js/data.js из jar: python3 tools/build.py WarStr.jar

РАЗМЕР ЭКРАНА (главное)
  Игра при запуске подгоняется под окно: размер игрового вида считается из размера окна и «Масштаба игры»
  (кратно тайлу 30×20, минимум оригинальные 240×320). Пиксели остаются нормального размера, на большом экране видно
  БОЛЬШЕ КАРТЫ; интерфейс привязан к краям: левая/правая софт-клавиши ✓/✕ — в нижних углах, верхняя панель с миникартой —
  слева сверху, нижняя панель групп — по центру снизу, диалоги и меню — по центру.
  ⚙ → «Масштаб игры»: меньше — больше карты и мельче интерфейс (применяется после перезапуска игры).
  Если окно повернули/изменили, появится кнопка «подогнать (перезапуск)».
СЕНСОР
  Один палец:  тап по карте — курсор в клетку под пальцем + OK (нижние углы — левая/правая софт-клавиша);
               перетаскивание — стрелки (курсор/прокрутка карты, пункты меню).
  Два пальца:  щипок — лупа (увеличивает картинку, до 5×), перетаскивание — сдвиг. ⟲ — сброс лупы.
  Экранные кнопки: крестовина, OK, L/R, панель «123 * #». Вибро-отклик. ⛶ — полный экран.
КЛАВИАТУРА/МЫШЬ
  Стрелки, Enter/Space = OK, Q/F1 и W/F2 = софт-клавиши, 0–9, E = *, R = #. Колесо мыши — лупа, клик — OK.

Вводные окна (страна/SMS, обновления, звук) пропущены (startup.js): игра сразу открывает главное меню, звук включён.
Чтобы вернуть оригинальные окна: убери <script src="startup.js"> из index.html и очисти localStorage сайта.
Сервер gear-games.com давно недоступен — онлайн-функции игры не работают. Сохранения — в localStorage браузера.
