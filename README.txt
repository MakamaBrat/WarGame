Art of War 2 — Global Confederation: нативный веб-порт (без эмулятора и без Java).

Запуск: открыть index.html (работает и с file://), либо выложить папку на любой хостинг.
Файлы: index.html (страница, раскладка, настройки), touch.js (жесты), runtime.js (MIDP: Canvas 2D, RMS, PNG, MIDI),
       game.js (игра, транслированная из байткода WarStr.jar), data.js (ресурсы), startup.js (пропуск вводных окон).
Пересборка game.js/data.js из jar: python3 tools/build.py WarStr.jar

СЕНСОР
  Один палец:   тап — OK (нижний левый/правый угол — левая/правая софт-клавиша ✓/✕);
                перетаскивание — стрелки (курсор и прокрутка карты, пункты меню).
  Два пальца:   щипок — зум (до 5×), перетаскивание — сдвиг увеличенной картинки. ⟲ — сброс зума.
  Экранные кнопки: крестовина, OK, L/R (софт-клавиши), панель «123 * #» (цифры игры). Кнопки можно скрыть.
  Вибро-отклик при нажатиях (отключается).
ЭКРАН
  ⛶ — полный экран. По умолчанию картинка и интерфейс РАСТЯНУТЫ на весь экран (без полос).
  ⚙ → «Растянуть на весь экран» 0–100%: 100% — на весь экран (пропорции искажаются, на широком окне сильно),
  0% — без искажений (с полосами по краям, они заливаются размытой копией картинки).
  ⚙ Настройки: масштаб (вписать / пиксель / по ширине), зум ±, чёткая или гладкая картинка,
  «Больше карты (270×340)» — показывает поля карты за краями обычного окна игры, чувствительность свайпа.
  Настройки сохраняются.
КЛАВИАТУРА/МЫШЬ
  Стрелки, Enter/Space = OK, Q/F1 и W/F2 = софт-клавиши, 0–9, E = *, R = #. Колесо мыши — зум, клик — OK, перетаскивание — стрелки.

Вводные окна (страна/SMS, обновления, звук) пропущены: игра сразу открывает главное меню, звук включён (startup.js).
Чтобы вернуть оригинальные окна: убери <script src="startup.js"> из index.html и очисти localStorage сайта.
Сервер gear-games.com давно недоступен — онлайн-функции игры не работают. Сохранения — в localStorage браузера.
